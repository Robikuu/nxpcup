DRV8871 Decay Mode Asymmetry (hbridge.c):
In HbridgeSpeed():   For positive speeds (scaled > 0), DirPin is set to 1U and PWM is inverted (100 - scaled). That drives the DRV8871 between (1, 0) (Drive) and (1, 1) (Slow Decay / Active Brake).   For negative speeds (scaled < 0), DirPin is set to 0U and duty is set to (mag * mag) / 100.0f. That drives the DRV8871 between (1, 0) (Reverse Drive) and (0, 0) (Fast Decay / High-Z Coast)!   Because Fast Decay lets the motor coast during the PWM off-time, and (mag * mag) / 100.0f crushes small negative commands (e.g. -25% becomes 6.25% duty cycle in coast mode), your inside wheel has almost zero reverse braking torque when pivoting in tight corners. To get linear, symmetric torque in both directions on a DRV8871 with 1 PWM + 1 GPIO per motor, you either need PWM on both pins or you must account for back-EMF threshold in Fast Decay rather than squaring down the duty cycle.   12.
